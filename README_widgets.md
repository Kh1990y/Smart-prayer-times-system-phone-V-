# ودجات المواقيت (v.29.3)

## أولاً: ما الذي يعمل على جوالك الآن؟
أندرويد وآيفون **لا يدعمان** ودجات الـ Manifest للمواقع (هذه الميزة تعمل حالياً في لوحة ودجات ويندوز 11 فقط). لذلك أضفت لجوالك الحلول التالية، وكلها تعمل الآن:

### ١) منشئ الودجات `widget.html`
افتح: `https://kh1990y.github.io/Smart-prayer-times-system-phone-V-/widget.html`
أو من التطبيق: الإعدادات ← العرض ← «فتح منشئ الودجات».

| نوع الودجت | ماذا يعرض |
|---|---|
| الصلاة القادمة | اسمها ووقتها وعدّاد تنازلي حيّ |
| جدول اليوم | الصلوات الست مع إبراز القادمة |
| الساعة والتاريخ | الساعة واليوم والتاريخ الهجري والميلادي |
| التاريخ الهجري | اليوم الهجري كبيراً مع الشهر والسنة |
| ذكر | ذكر يتجدد كل ٤٥ ثانية بحجم خط يملأ المساحة |
| لوحة كاملة | الساعة + القادمة + الجدول + ذكر |

الأحجام: مربع ٢×٢ • عريض ٤×٢ • شريط ٤×١ • طويل ٢×٤ • كبير ٤×٤ • ملء الشاشة • **حجم مخصص** (اكتب العرض والارتفاع بالبكسل).
والألوان: حسب التطبيق / الحالي / الزمرد / الغسق / الداكن / الفاتح، والمدينة، وأرقام 123 أو ١٢٣، وخلفية شفافة.

**طريقة وضعه على الشاشة الرئيسية:**
١. اختر الشكل ثم اضغط «فتح الودجت».
٢. أندرويد (كروم): ⋮ ثم «إضافة إلى الشاشة الرئيسية». آيفون (سفاري): زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».
٣. يظهر بأيقونة مستقلة ويفتح بالشكل الذي اخترته. كرر الخطوات لإنشاء أكثر من ودجت بأشكال مختلفة.

> هذا ليس ودجت حيّاً داخل الشاشة الرئيسية؛ هو صفحة تفتح بملء الشاشة. الودجت الحيّ الحقيقي على أندرويد وآيفون يحتاج تطبيقاً أصلياً (Kotlin / Swift).
> تقدر أيضاً تضع الرابط في تطبيقات تعرض صفحات الويب كودجت (مثل KWGT على أندرويد).

### ٢) اختصارات الأيقونة (أندرويد)
اضغط مطولاً على أيقونة التطبيق: «مواقيت اليوم» • «الصلاة القادمة» • «ذكر» • «ودجات المواقيت».

## ثانياً: ودجات Manifest الحقيقية (ويندوز 11)
في `manifest.webmanifest` خمسة ودجات: الصلاة القادمة • جدول اليوم • التاريخ الهجري • ذكر • لوحة كاملة، بقوالب Adaptive Cards في مجلد `widgets/`.
- يحسب الـ Service Worker (`sw.js`) البيانات من نسخة المواقيت التي يحفظها التطبيق (تتضمن تعديلات الأذان)، ويحدّث الودجات كل ساعة تقريباً وعند الاستئناف.
- حسب توثيق مايكروسوفت يجب نشر التطبيق كحزمة ويندوز (عبر pwabuilder.com) ليظهر في لوحة الودجات؛ ويتطلب ويندوز 11.
- لم أستطع اختباره على ويندوز حقيقي هنا؛ اختبرت منطق الحساب وتوسعة القوالب فقط. التحديث دوري وليس لحظياً، فالعدّاد التنازلي الحيّ موجود في ودجات الجوال فقط.

## التحديث
ارفع الملفات الجديدة إلى GitHub، وغيّر `VERSION` في `sw.js` كلما غيّرت الملفات.
