# النسخة المحمولة (v.29.2) — تطبيق ويب قابل للتثبيت (PWA)

ملف واحد للنظام يعمل على أندرويد وآيفون وآيباد. بعد التثبيت يظهر بأيقونته على الشاشة الرئيسية ويفتح بملء الشاشة ويعمل بدون إنترنت.

## محتويات المجلد
| الملف | وظيفته |
|---|---|
| `index.html` | النظام نفسه (v.29 + تعديلات الجوال) |
| `manifest.webmanifest` | اسم التطبيق وأيقوناته وألوانه |
| `sw.js` | يحفظ الصفحة لتعمل بدون إنترنت |
| `icons/` | الأيقونات |


## التثبيت على أندرويد
1. افتح الرابط في **Chrome**.
2. اضغط ⋮ ثم **تثبيت التطبيق** (أو **إضافة إلى الشاشة الرئيسية**). وتجد أيضاً زر «تثبيت التطبيق الآن» في الإعدادات ← العرض.
3. افتحه من أيقونته. للإبقاء على الشاشة مضاءة: الإعدادات ← العرض ← «إبقاء الشاشة مضاءة» ← تشغيل.

## التثبيت على آيفون / آيباد
1. افتح الرابط في **Safari**.
2. اضغط زر المشاركة ⬆ ثم **إضافة إلى الشاشة الرئيسية** ثم **إضافة**.
3. افتحه من الأيقونة. (إعدادات التطبيق المثبّت منفصلة عن سفاري، فاختر المدينة والثيم مرة أخرى.)

## التحديث لاحقاً
1. استبدل `index.html` في GitHub بالنسخة الجديدة.
2. في `sw.js` غيّر رقم `VERSION` (مثلاً `prayer-v29.2-2`) ثم احفظ.
3. يتحدّث التطبيق عند الفتح التالي بوجود إنترنت.

## صورة الإعلان
تعمل كما هي: من `images/promo.jpg` في نفس المستودع أو من raw.githubusercontent.

## حدود يجب معرفتها
- لا يمكن لتطبيق الويب تشغيل صوت الأذان أو إشعارات والجوال مقفل؛ هو شاشة عرض تعمل أثناء فتحه. التنبيه الصوتي في الخلفية يحتاج تطبيقاً أصلياً.
- آيفون: إبقاء الشاشة مضاءة يتطلب iOS 16.4 أو أحدث.
